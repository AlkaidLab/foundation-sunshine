# Foundation Sunshine NVIDIA RTX Video components

This directory is managed by Foundation Sunshine and its Control Panel. It is
not a general-purpose DLL search path. Sunshine recognizes only the fixed file
roles and trusted hashes supported by the installed release.

## Files and ownership

| File | Role | Ownership and terms |
| --- | --- | --- |
| `foundation_rtx_video_adapter.dll` | Foundation Sunshine adapter for the NVIDIA SDK | Project-authored GPL-3.0 code, installed with Sunshine and loaded only when RTX HDR is selected |
| `nvngx_truehdr.dll` | NVIDIA NGX runtime for SDR-to-HDR processing | NVIDIA material governed by the terms supplied by NVIDIA; not licensed under Foundation Sunshine's GPL-3.0 license |
| `component.json` | Local compatibility and integrity metadata | Generated by the Control Panel; it does not grant rights to any DLL |

Sunshine resolves the adapter from this fixed component directory, verifies the
build-specific SHA-256 embedded in `sunshine.exe`, and loads it through a stable
C ABI. The installer does not bundle the Microsoft Visual C++ runtime required
by the adapter. Install the Microsoft Visual C++ 2015-2022 Redistributable (x64)
when the Control Panel reports that prerequisite as missing.

The project source, including the adapter, is available at:

https://github.com/AlkaidLab/foundation-sunshine

Foundation Sunshine license:

https://github.com/AlkaidLab/foundation-sunshine/blob/master/LICENSE

The current Foundation Sunshine integration implements only SDR-to-HDR through
`nvngx_truehdr.dll`. NVIDIA's published RTX Video SDK capabilities do not imply
that every listed effect is implemented or supported by this Sunshine release.

Adapter builds made with the development NGX Application ID `0` expire fourteen
days after they are built. An adapter built with an NVIDIA-assigned Application
ID does not use this development expiry.

If you convey the project-authored adapter or a modified version of it, the
GPL-3.0 requirements applicable to that covered code continue to apply,
including preservation of notices and availability of corresponding source.
The actual license controls; this README does not add restrictions to GPL-3.0
or decide whether a separate work forms a combined work.

# Foundation Sunshine NVIDIA RTX Video 组件

此目录由 Foundation Sunshine 及其控制面板管理，并非通用的 DLL 搜索目录。
Sunshine 只会识别当前安装版本支持的固定文件角色和可信哈希。

## 文件与权利归属

| 文件 | 用途 | 权利归属与适用条款 |
| --- | --- | --- |
| `foundation_rtx_video_adapter.dll` | Foundation Sunshine 对 NVIDIA SDK 的适配组件 | 项目自研 GPL-3.0 代码，随 Sunshine 安装，仅在选择 RTX HDR 时加载 |
| `nvngx_truehdr.dll` | 用于 SDR 转 HDR 处理的 NVIDIA NGX 运行库 | NVIDIA 材料，适用 NVIDIA 随文件提供的条款，不适用 Foundation Sunshine 的 GPL-3.0 许可证 |
| `component.json` | 本机兼容性与完整性元数据 | 由控制面板生成，不授予任何 DLL 的使用或分发权利 |

Sunshine 只从当前固定组件目录解析适配组件，校验编译进 `sunshine.exe` 的构建摘要后，
再通过稳定 C ABI 加载。安装包不附带适配组件所需的 Microsoft Visual C++ 运行库；
控制面板提示缺失时，请自行安装 Microsoft Visual C++ 2015-2022 运行库（x64）。
可信适配组件和运行库摘要均固化在 Core 中；component.json 仅记录安装状态，不能扩展信任范围。
运行库未改变时，重新构建适配层不会改变其版本身份。

项目源码（包括适配层源码）：

https://github.com/AlkaidLab/foundation-sunshine

当前 Foundation Sunshine 仅通过 `nvngx_truehdr.dll` 接入 SDR 转 HDR。
NVIDIA 公布的 RTX Video SDK 能力不代表本 Sunshine 版本已经实现或支持其中的全部功能。
