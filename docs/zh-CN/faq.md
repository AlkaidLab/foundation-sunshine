# FAQ 与排障

[项目首页](../../README.md) · [文档目录](README.md) · [English](../en/faq.md)

按遇到的现象排查。首次安装与 PIN 配对步骤见 [README](../../README.md#快速开始)，功能开启步骤见[功能与设置](features.md)。

## 画面卡顿 丢帧或操作延迟高

### 1 先建立能稳定运行的基础配置

在控制端把分辨率设为 **1080p**、帧率设为 **60 FPS**、码率设为 **10 Mbps**，暂时关闭 HDR、超分、插帧和其他画质增强。Sunshine 保持自动编码；如果有编码兼容问题，先用 H.264。被控电脑优先接网线，无线控制设备优先使用 5 GHz 或 6 GHz Wi-Fi，并靠近路由器。

断开后重新连接 **Desktop**，拖动窗口或播放视频测试，再进入游戏。静态桌面帧率降低通常是按画面更新发送的结果；应在画面持续运动时判断卡顿。

### 2 打开性能统计 找到问题在哪一段

在控制端设置或连接菜单中开启 **性能统计／性能浮窗**，同时查看 Sunshine GUI 的运行状态或日志。不同客户端的字段与统计方式可能不同。

| 看到的现象 | 先查什么 | 下一步 |
| --- | --- | --- |
| 网络丢帧、延迟或抖动明显升高 | Wi-Fi、链路带宽、上传拥塞 | 降码率；尝试两端有线或靠近路由器，暂停大流量上传下载后对比 |
| 网络正常，但被控端编码耗时高或 FPS 不足 | 显卡负载、游戏帧率、编码设置 | 降游戏画质或连接分辨率，确认用了硬件编码；暂时关闭 RTX HDR / DLSS NR 后对比 |
| 网络和被控端正常，控制端解码耗时高 | 硬件解码、所选编码格式、设备发热 | 确认使用硬件解码；换回 H.264 或 HEVC，降低分辨率，再检查是否随时间升温降频 |
| FPS 看似正常，画面仍周期性顿一下 | 屏幕刷新率、帧率、帧队列与同步 | 先把连接帧率设为与屏幕匹配的 60 FPS，并让游戏稳定运行；再比较客户端的默认帧节奏设置 |
| 游戏本地也卡顿 | 游戏本身和被控电脑性能 | 先解决本地掉帧；远程连接不会把本地卡顿变流畅 |

60 FPS 的每帧间隔约 **16.7 ms**，120 FPS 约 **8.3 ms**。用这个量级判断处理是否跟得上，不要把网络、解码等不同统计字段直接相加当作完整端到端延迟。

### 3 稳定后 一次只提高一项

先恢复 20 Mbps，再提高分辨率或帧率。每次只改一项，用同一场景比较；确认正常后再启用 HDR、画质增强和多声道。不要一开始就追求 4K、高帧率和最高码率。

外网卡顿还要检查被控端上传带宽、控制端下载条件，以及组网是否实际使用直连或中继。局域网流畅不能证明外网路径也有同样表现。

### 4 仍无法解决时 提交可复查的结果

反馈两端版本、CPU/GPU、网络连接方式、分辨率／帧率／码率／编码格式，附上卡顿时的性能统计截图和对应日志，并说明是否在基础配置下仍然复现。指标含义可参考 [Moonlight 官方说明](https://github.com/moonlight-stream/moonlight-docs/wiki/Frequently-Asked-Questions#what-do-the-numbers-mean-in-the-on-screen-connection-statistics)。

## 安装模拟 DS5 组件后 Windows 桌面或菜单自动滚动

如果安装模拟 DS5 手柄组件后，Windows 桌面或菜单出现自动滚动，可以[下载并安装最新测试版 Foundation Sunshine](https://github.com/AlkaidLab/foundation-sunshine/releases)尝试解决。选择标记为 **Pre-release** 的最新版本，更新步骤见[升级说明](upgrading.md)。

若更新后仍复现，请反馈 **Windows 版本、Sunshine 版本和复现步骤**，方便继续定位。

## 找不到电脑

先按 [README 的查 IP 步骤](../../README.md#3-添加电脑并配对)手动添加 IPv4 地址。仍无法连接时，依次检查 Sunshine 是否正在运行、两台设备是否处于同一局域网，以及 Windows 防火墙是否允许 Sunshine 通信。访客 Wi-Fi 或无线隔离可能使设备无法互相访问。

## 配对成功但黑屏或启动失败

先连接 **Desktop**。回到新手向导或显示设置，确认选择的显示器已开启；如果使用虚拟屏幕，先检查驱动状态。仍然失败时，记录报错时间，在日志或故障排除页保存对应日志，并附上显卡和驱动版本反馈。

## 有画面但没有声音

在被控电脑播放音频，确认 Windows 本机有声音；再检查 Sunshine 的音频输出设备。客户端先设为 **立体声 / Opus**，断开后重新连接。确认正常后，再逐项启用多声道或其他音频格式。

## 在家能连，在外面连不上

局域网地址不能直接用于外网。先完成局域网连接，再参考官网文档与社区说明配置远程网络访问：[官网](https://www.alkaidlab.com/) · [国内官网](https://www.alkaidlab.cn/)。

## 反馈问题

仍无法解决时，附上被控端与控制端版本、设备型号、复现步骤和对应时间段的日志，前往 [GitHub Issues](https://github.com/AlkaidLab/foundation-sunshine/issues) 或 [QQ 交流群](https://qm.qq.com/cgi-bin/qm/qr?k=5qnkzSaLIrIaU4FvumftZH_6Hg7fUuLD&jump_from=webapi)。
