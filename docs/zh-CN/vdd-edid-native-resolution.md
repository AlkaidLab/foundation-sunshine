# EDID 原生分辨率

[项目首页](../../README.md) · [功能与设置](features.md) · [English](../en/vdd-edid-native-resolution.md)

部分游戏会根据 EDID 中的原生分辨率或宽高比筛选全屏选项，即使 Windows 已提供更高分辨率。
此 Windows 设置用于改善这类兼容性问题，需要支持 `CREATEMONITOR` 原生尺寸选项 的 ZakoVDD 版本。
有效的自定义 EDID 优先于此设置。

## 选择并确认原生分辨率

1. 在 Windows 的 WebUI 中打开 **音视频 → 虚拟显示器 → 高级 → EDID 原生分辨率**。
2. 选择 **默认（1920×1080）**，或从**公布的分辨率**中选择已有尺寸，也可以使用自行添加的尺寸。添加分辨率不会自动将其选为原生分辨率。
3. 如果同时修改了公布的分辨率或 FPS 列表，点击**应用**，让 Sunshine 重新加载模式列表。如果只修改 EDID 选项，点击**保存**。
4. 在系统托盘关闭 **VDD 常驻模式**，并禁用 **VDD 复用**，使 Sunshine 能移除并重新创建虚拟显示器。在 Moonlight 中选择**退出会话（Quit Session）**，然后重新连接。
5. 重新启动游戏，检查其全屏分辨率选项。实际串流模式仍由会话或客户端选择。

如果 VDD 是唯一显示器，Sunshine 的正常会话清理流程会保留它。此时仅重新连接无法应用 EDID 更改，
保存的选项要等到显示器被安全重建后才会生效。这种配置不支持仅通过重连刷新 EDID；本说明不要求或建议强制销毁唯一的显示器。

仅保存不会让运行中的 Sunshine 重新加载公布的模式列表。新添加的尺寸未应用时，Sunshine 可能仍通过
`SETMODES` 发送旧列表；驱动会拒绝实际列表中不存在的原生尺寸，并使用原始 EDID。此流程无需重启 Windows 显示适配器。

## 选择限制

默认选项保留原始 EDID。明确选择的尺寸必须保留在配置列表中，并且至少有一个配置的刷新率可编码为
EDID 详细时序。刷新率按会话模式列表的规则取整。无效或不可编码的选项仍可见，但不可选择。
移除当前尺寸后，它会显示为不可用，必须明确选择默认或其他有效尺寸才能保存；不会静默改选。

每个尺寸分量必须在 1..4095 之间，像素时钟也必须能写入 EDID 详细时序字段。因此 `5120x1440`
不能作为此原生时序；仅提供 120/144 Hz 时，4K 也无法编码。此限制不会缩小驱动的一般显示模式列表。

## 保存与兼容性

WebUI 仅将 `vdd_edid_native_resolution=default|WIDTHxHEIGHT` 保存到 Sunshine 配置。
创建显示器时，主机读取已保存的选择，并通过 `CREATEMONITOR` 传递明确指定的尺寸。
默认选项不发送可选尺寸，保留原始 EDID。不会将 EDID 首选项写入驱动 XML 或注册表；
即使没有 VDD XML，也可以保存此选择。

旧 API 客户端省略该字段时，会保留 Sunshine 中已保存的选择。
部分保存请求会保留省略的分辨率或 FPS 列表；明确提交的列表（包括空列表）会替换原值。
如果请求和已保存配置都没有某个列表，会使用主机当前公布的列表。
创建显示器时，启动命令行覆盖值优先；保存操作只更新磁盘上的选择。API 会检查列表成员、尺寸和时钟。
旧客户端若修改任一公布的模式列表，保留的选项也必须仍受支持；否则在修改配置文件之前拒绝请求。
移除选中尺寸或其可编码刷新率前，请明确选择默认或其他受支持尺寸。
驱动一般模式和 GPU 设置的现有 XML 保存逻辑与 EDID 首选项相互独立。
API 会在同一配置锁内校验并保存两个配置。如果 Sunshine 写入失败，会在允许下一次保存前恢复原始 XML 字节。
空模式列表有效，会使用驱动的后备模式。恢复失败会记录到日志；如果保存时进程崩溃或机器发生故障，此机制不提供故障恢复。

### API 请求格式

`POST /api/config` 保存完整配置。EDID 首选项、模式列表和现有受保护字段有保留规则；
其他省略的非受保护字段（例如 `adapter_name`）会被移除，可能重置主机或 GPU 设置。
请提交完整配置以保留这些字段。

`resolutions` 和 `fps` 必须以字符串提交。以下仅为完整请求中的列表字段片段：

```json
{"resolutions":"[1920x1080]","fps":"[60]"}
```

明确清空列表时使用字符串 `"[]"`；这些字段不支持 JSON 数组。

### 驱动兼容性

此功能需要由 Sunshine 捆绑的、支持 `CREATEMONITOR` 可选原生尺寸的已签名 ZakoVDD 版本。
旧驱动会忽略可选参数组。
驱动会独立检查实际模式列表，在可编码且受支持的刷新率中选择最接近 60 Hz 的值。
有效自定义 EDID 的优先级、显示模式顺序和 IddCx 首选索引保持不变。
驱动内部重建显示器时会保留原始创建请求，包括原生尺寸选项。
