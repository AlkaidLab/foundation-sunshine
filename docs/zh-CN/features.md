# 功能与设置

[项目首页](../../README.md) · [文档目录](README.md) · [English](../en/features.md)

完成 [README 的首次连接](../../README.md#快速开始)后，再配置下面的功能。每节先说明用途，再给出开启方法和确认方式。

## 画面与显示

### HDR 与色彩

手机、平板和电视的亮度不同。Foundation 会采用控制端上报的屏幕能力，为当前连接设置亮度目标；使用物理显示器时，默认保留电脑本地的 HDR 和色彩设置。

支持 PQ / HLG 输出，逐帧场景亮度分析，以及 HDR10+、HDR Vivid 动态信息。Dolby Vision 提供 Profile 8.1 / 8.4 协商和主机侧信息注入。每个配对设备可单独配置亮度，虚拟屏可以读取 Windows HDR Calibration 校准结果，物理屏可按需覆盖 ICC 配置并在连接结束后还原。

**开启与确认：**

1. 先确认控制设备、显示屏和所选客户端支持 HDR，再在客户端开启 HDR。
2. 在 Sunshine 的视频设置中选择显示器及 HDR 策略。使用基地显示器时，先完成下一节的驱动安装。
3. 在配对设备设置中优先使用客户端上报亮度；需要校准时，再设置手动亮度或安装好的颜色配置文件。
4. 开启场景自适应 HDR 后，查看控制面板中的实时状态；再查看客户端显示的实际视频格式及回退信息。

主机协商或注入状态不等于接收屏幕已按该格式呈现。动态 HDR 的实际效果由客户端、系统、显示设备和编码路径共同决定。


### 基地虚拟显示器 ZakoDisplay

**无需连接物理显示器，也可以直接创建虚拟屏幕，远程使用电脑桌面和游戏。** [ZakoDisplay](https://github.com/qiin2333/zako-vdd) 支持 HDR、自定义分辨率与刷新率，按连接创建和释放屏幕，并为客户端保留对应的显示配置。

提供多种屏幕组合：只使用基地虚拟屏、保留物理屏并扩展虚拟屏、将目标屏幕设为主屏，或仅启用指定屏幕。可以为手机设置竖屏、为平板设置合适的分辨率，也可以在远程使用时停用电脑的物理屏幕。

**开启与确认：**

1. 在 Windows 的 Foundation 桌面 GUI 中打开基地显示器设置，检查驱动状态；安装时未选择驱动或驱动异常时，再安装或修复。
2. 确认驱动状态可用；若提示需要重启，先重启 Windows。
3. 在新手向导或显示设置中选择基地显示器，设置分辨率、刷新率和屏幕组合策略。
4. 从 Moonlight 开始连接，检查画面尺寸与 Windows 显示布局；结束连接后确认本地显示状态恢复。

兼容的控制端还可调整屏幕旋转、Windows 显示缩放及连接分辨率。不要把多客户端显示配置理解成多个互相隔离的 Windows 桌面。


## 捕获 编码与性能

Zako Direct 直接取得基地虚拟屏生成的画面。在支持的路径上借用 GPU 帧，减少捕获环节的拷贝；交接不可用时退回复制路径，直接捕获初始化失败时可回退到 Desktop Duplication。

另有 Windows Graphics Capture（WGC）、Desktop Duplication 和 AMD Display Capture。WGC 可以捕获指定窗口，包括应用或插帧软件的输出；AMD Display Capture 不适用于基地虚拟屏。

**开启与确认：**

1. 使用基地显示器时，在视频设置的“强制指定捕获方法”选择 **Zako Direct**。
2. 需要传送单个窗口时，选择 WGC 和窗口捕获目标，填写窗口标题；WGC 需要用户模式，不能在 SYSTEM 服务模式下使用。
3. 根据客户端解码能力选择视频编码格式，再检查日志中的实际捕获方法和编码器。出现异常时先回到自动捕获和默认编码设置。

### NVIDIA 画质增强

RTX HDR 可把 SDR 游戏转换成 HDR 输出；DLSS NR(DLSS5) 提供可选的编码前画面增强，并可在连接中调节。开启这些处理会占用额外 GPU 时间。

在桌面 GUI 的画质增强管理页安装所需组件，再在应用设置中开启。先确认当前游戏能正常连接，再逐项启用并比较画面与延迟。RTX HDR 不处理原生 HDR 或 HLG 输入；组件状态以 GUI 提示为准。


编码方面支持 NVIDIA NVENC、AMD AMF、Intel Quick Sync 与软件编码，实际视频格式由显卡和控制端能力决定。Foundation 对捕获与编码链路、实时画质调整和网络自适应进行了优化；使用时可通过主机运行状态和控制端性能统计确认实际表现。

## 音频与麦克风透传

控制端接收电脑声音，也可以把本地麦克风传回电脑，用于游戏语音或通话。Opus 支持最高 7.1.4 声道；另有 PCM、AC3、E-AC3，当前最多 5.1。音频丢包恢复和静音保活用于减少网络波动、安静片段后的播放问题。

**开启与确认：**

1. 在被控电脑播放声音，确认 Windows 本机音频正常。
2. 在 Sunshine 选择音频输出设备；首次连接在控制端使用 **立体声 / Opus**。
3. 确认正常后，按实际扬声器或功放能力选择声道与编码。PCM 占用更多带宽，AC3 / E-AC3 是否直通由控制端和接收设备决定。
4. 使用远程麦克风时，在设备中心检查麦克风组件与设备，在控制端授予麦克风权限并开启回传，再用被控电脑的录音应用测试。


## 桌面控制面板

除 Sunshine 的 WebUI 外，Foundation 提供独立 Windows 桌面 GUI，将设备组件、游戏库、运行状态、日志和更新集中管理。

- **设备与驱动：** 基地显示器有独立的设置入口；设备中心管理手柄、麦克风、虚拟鼠标与 USB 传输组件。部分组件可在安装 Sunshine 时选择安装。
- **游戏库：** 扫描 Steam、Epic、GOG 或本地目录，批量添加应用和整理封面。
- **运行管理：** 查看连接和资源状态，管理服务运行，检查日志与更新。
- **诊断与辅助：** 本地日志分析；配置模型服务后，可使用 AI 日志诊断、名称和封面整理。

从 Windows 上的 Foundation Sunshine 快捷方式打开。浏览器 WebUI 可用于常规配置；驱动安装、本地扫描等系统操作需在桌面 GUI 中完成。


## 键鼠 触控与手柄

精确式触控板、客户端光标和文本输入状态同步，需要支持对应扩展的控制端。手写笔旋转也是客户端协议扩展，不能仅凭设备有手写笔就判断可用。


### DualSense 与虚拟手柄

Foundation Sunshine 提供 DualSense 设备组件。在 **设备中心 → 控制器** 安装后，可在被控电脑上呈现原生 DualSense，让支持的游戏像识别 USB 接入 PC 的手柄一样使用自适应扳机、音频触觉、灯光和触控板等功能；实际反馈需要游戏、控制端和连接方式共同支持。

**开启与确认：**

1. 在设备中心安装 DualSense 组件，确认组件可用。
2. 选择全局虚拟手柄类型，或为单个游戏选择 DualSense；也可按游戏选择 Xbox 360 或 DualShock 4。
3. 在控制设备上连接实体手柄，再开始远程连接，先确认基础按键和摇杆输入。
4. 用支持对应特性的游戏检查扳机、触觉等反馈。音频触觉还需配套传输组件，按设备中心提示安装。

改变类型会应用到之后新建的虚拟手柄。若安装模拟 DS5 组件后桌面或菜单自动滚动，见 [FAQ](faq.md#安装模拟-ds5-组件后-windows-桌面或菜单自动滚动)。


## 桌面协作与连接管理
剪贴板可双向同步文字和图片。文件夹共享只开放选择的目录，并按配对设备授权。先在被控端开启相应功能、添加目录和权限，再从控制端的剪贴板或主机文件入口使用。USB 转发需要安装传输组件，并明确授权要转发的设备。



兼容控制端可以在连接中调节码率、帧率和分辨率。自适应码率与视频丢包保护使用客户端的网络反馈调整连接；它们不能替代两端网络互通的配置。

先在局域网完成首次连接，再在控制端开启自适应码率或调整画质。网络不稳定时先降低码率，记录实际丢包和延迟，再逐项调整。电脑远端命令、休眠、最后一个视频会话结束后退出应用，以及 Webhook 事件通知都属于按需设置的会话功能。


## 其他集成与实验性功能

- **Moonlight Web：** 桌面 GUI 可下载、配置和启动第三方网页客户端组件；Sunshine 管理网页本身不是远程桌面客户端。
- **二维码配对：** 界面标为局域网实验功能，需要扫码控制端。新用户优先按 README 的 PIN 流程配对。
- **PyroWave：** 实验性视频路径，需要匹配的控制端和运行组件。

相关开发资料与实现入口见[开发文档](development.md)。
