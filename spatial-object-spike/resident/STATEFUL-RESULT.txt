Implementation
--------------
stateful_tap.cpp uses the verified Microsoft encoder wrapper only and copies raw
property flags + a loss epoch, with all 2048 float sample slots still available.
It does NOT install the sanitizer diagnostic hook or copy 640-byte traces.
position_cache.h runs in the collector, never the audio callback. Flag 0x4 updates
XYZ; flag 0x2 updates volume; create/end handle lifetimes. Missing initial position
is NaN/unknown, not zero. Static channel positions remain implicit in channel type.
The cache is bounded at 4096 keys; generation protects observed ID reuse. A loss
epoch invalidates all state/identity conservatively. Extended-reader calls are
unsupported and cause the current default collector to stop unsuccessfully.

collector.exe/start-resident.ps1/run-test.ps1 default to Dolby stateful output.
Disk v2 uses 112-byte headers including flags, quality, generation, loss epoch and
raw XYZ, plus reconstructed current XYZ and audio. Legacy tools expecting 64-byte
records must NOT be used; use verify_stateful.py. Legacy explicit backends remain.
The supervisor now uses one collector per engine lifetime and rotates output files
without clearing its cache or reinstalling hooks. Quota stops safely, no auto-delete.
