Implemented
-----------
The plugin publisher now has a read-only exact-engine/hash/six-entry preflight,
explicit --continuous mode, and retained --max-seconds 1..60 diagnostic bounds.
Missing/malformed bounds cannot silently request continuous capture. Intentional
stop before any object input restores cleanly without fabricating native readiness
or an empty successful EOS. Existing object/format/watchdog constraints remain.

manage-live.ps1 provides explicit Preflight / Start / Status / Stop. Start checks
the reviewed source/binary manifest, creates immutable hash-named deployment and
records publisher PID/creation/image/hash, exact private event/pipe and host config
snippet. It does not emit objects, change endpoints, edit installed configuration,
elevate, retry, install a service, force-kill or unload DLLs. WaitingForObjects is
distinct from NativeReady. Stop checks process identity/hash and six-entry restore.
Continuous mode is implemented but sustained native operation is unverified.
