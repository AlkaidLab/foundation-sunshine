# Icon files

- Sun (generated, tray and favicon): sunshine.ico (the host tray icon on Windows and the favicon of the Web UI, which the host serves from this file), logo-sunshine-16.png (tray elsewhere), sunshine-<playing|pausing|locked>.ico and their -16 / -45 / 1024 png.
- Vivi (unchanged art): logo-sunshine-256.png (also the apple-touch-icon), logo-sunshine-45.png, logo-sunshine-1024.png, and assets/brand/sunshine.{ico,icns,png,svg} (the exe resource and the installers).
- Which art goes where: the cloudless sun (foundation-ui src/assets/app/app-icon.svg; source and permission in that directory SOURCE.md: SunshineQ, file 素材/无云.svg, permission of AlkaidLab in the group chat 2026-11-08) is used ONLY for the smallest icons: the tray icons with their play / pause / lock badge variants, the browser favicon, and the title-bar glyph in the app. Everything else is Vivi (the character art; sources: foundation-ui src/assets/vivi, built by scripts/build-vivi-assets.py). The sun files are generated by foundation-ui tools/app-icons/gen.py; sizes up to 32 px come from a hinted copy of the SVG (thicker outline, eyes, mouth) and the badges are drawn by the generator. Not for use outside the products. ICO files: 256 px entry PNG, smaller ones 32-bit BMP.

- Sparxie mark: sparxie-mark-64.png (64 px, transparent; shown at 16-24 px in the Sparxie chips, the section headers of a Sparxie application and the two entries of the add menu). Art: the Sparxie character (chibi with the top hat) by 暗檬, the author of Sparxie; used in the products with the permission of its author (2026-11-10). Vectorised by the controller (visioncortex VTracer 0.6.5, 6 flat colours); the vector source is assets/brand/sparxie-mark.svg. The art is not recoloured: it has a dark navy outline, so on dark surfaces it sits on a light round backing (foundation-ui .m-chip__img). Not for use outside the products.
